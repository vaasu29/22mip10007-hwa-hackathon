## 🐾 Product Concept

**Treasure Trails** is an original physical modular canine enrichment system designed to eliminate the predictability of traditional dog puzzle toys.

### The Problem
Most dog puzzles follow a rigid loop: **Puzzle → Solve → Treat → Repeat**. Once a dog learns the physical mechanism, cognitive stimulation drops and the toy is abandoned.

### The Solution: "One Toy. Hundreds of Trails."
Treasure Trails transforms playtime into a dynamic, multi-stage treasure hunt. Owners can easily rearrange interlocking modular sections to create an endless variety of scent, search, and solve routes:

1. **Scent-Search Pods**: Breathable chambers activating olfactory curiosity.
2. **Sliding Timber Gates**: Tactile snout and paw manipulation challenges.
3. **Rotating Puzzle Discs**: Circular turntables with progressive resistance.
4. **Arch Tunnels**: Spatial navigation and crawl-through obstacles.
5. **Paw-Activated Mechanisms**: Responsive switches rewarding physical dexterity.
6. **Branching Paths**: Divergent routes encouraging independent choice.
7. **Final Treasure Vault**: Climax reward chamber for triumphal conclusion.

## 🎨 Visual Direction & Aesthetic

The user interface is crafted in a **Soft Warm Editorial / Neo-Brutalist** style inspired by **PupSociety**:
* **Palette**: Warm cream background (`#FDF8F3`), pastel card accents (Soft Mint `#D2F4E2`, Blush Pink `#FFDFDF`, Lilac `#EFE3FF`), vibrant crimson CTA buttons (`#CE1B3D`), and deep espresso footer (`#230E10`).
* **Typography**: Expressive chunky display serif (`Fraunces`) paired with geometric body sans (`Plus Jakarta Sans`).
* **Tactile Accents**: 2px dark contours, offset pop shadows, starburst stickers, star twinkles, and signature overlapping circular quote badges.

## ✨ Key Interactive Features

* **🐶 Canine Dichromatic Vision Mode**:  
  Toggle between human RGB vision and canine 430nm (Blue) / 575nm (Yellow) spectrum view to understand how dogs perceive high-contrast toys and trails.
* **🔊 Zero-Dependency Web Audio Synthesis**:  
  Tactile clicks, playful squeaks, treat clinks, and unlock chimes generated directly via the browser Web Audio API.
* **🛍️ Atelier & Goods Slide-Over Catalog**:  
  Complete catalog containing Italian leather leashes, solid brass collars, weighted ceramic bowls, and modular adventure kits.
* **🛒 Full E-Commerce Flow**:  
  Interactive Cart Drawer with real-time price calculations, quantity management, promo code validation, and a simulated checkout screen with unique order IDs (`TT-XXXXXX`).
* **📰 Editorial Journal & Studio Modals**:  
  Interactive reading views for print journals, material sustainability breakdowns, and Brannan Street Studio visitor guides.
* **✉️ Working Society Membership Enrollment**:  
  Email newsletter and membership selection ($120/year or $12/month) with instant celebratory confirmation.

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/vaasu29/22mip10007-hwa-hackathon.git

# 2. Enter project directory
cd 22mip10007-hwa-hackathon

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
